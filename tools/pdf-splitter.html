How to Use

  1. Load a PDF file
  2. Set the page offset (which PDF page = which print page)
  3. Mark front/back matter zones
  4. Click pages to select, or type a print page range
  5. Download selected pages
Tip: Hold Shift and click to select a range between last clicked and current page.
